# Changelog

## 2.0.0 — Release-candidate polish

- Added file-aware preview modes for CSS, JSON, CSV/TSV, SVG, and imported image/PDF/audio/video assets.
- Source-only formats now use a focused editor layout rather than an unrelated browser pane; source files remain inert.
- Added fine appearance/editor customization: custom accent color, editor font size, line height, tab indentation, word wrapping, and reduced motion.
- Added release documentation, a permissive MIT license, GitHub Actions tests, and a static GitHub Pages deployment workflow.
- Bumped the service-worker app-shell cache and aligned package/UI versions.
- Added/extended tests for file type routing, format previews, asset sanitization, and release metadata.

Previous iterative releases are described in the repository's source history; this changelog starts with the first prepared 2.0.0 release candidate.
