AetherText for Windows
======================

Installer: run AetherText-Setup-x64.exe and follow the prompts.
Portable: extract AetherText-Portable-x64.zip, then run AetherText.exe.

AetherText stores its embedded-browser profile under your Windows local app data
folder, so workspace data can persist across launches. Use AetherText's own export
feature to keep independent backups of important documents.

The desktop host uses Microsoft's WebView2 Runtime. If it is missing, AetherText
will offer to open Microsoft's official download page:
https://developer.microsoft.com/microsoft-edge/webview2/

Only download AetherText from the project's official GitHub Releases page.
